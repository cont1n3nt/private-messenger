# Private Messenger 🔐
PIZDA 3
A lightweight encrypted messaging system built for secure communication between trusted users. 

---

## 🚀 Features

- End-to-end encrypted messages
- Secure authentication system
- Private peer-to-peer communication
- Minimal latency messaging
- Lightweight API backend

---

## 🧠 Tech Stack

- Python / Node.js (depending on backend)
- WebSocket / HTTP API
- JWT / custom auth layer
- PostgreSQL / SQLite (for message storage)
- Crypto library for encryption

---

## 🔒 Security

All messages are encrypted before being stored or transmitted.
No plaintext message data is exposed to the server layer.
