# Краткое руководство Git \& GitHub



## 1. Клонирование репозитория



```bash

git clone https://github.com/cont1n3nt/private-messenger.git

```



Перейти в папку проекта:



```bash

cd private-messenger

```



---



## 2. Перед началом работы



Переключиться на ветку dev:



```bash

git checkout dev

```



Получить последние изменения:



```bash

git pull origin dev

```



---



## 3. Работа с кодом



После изменений файлов проверь статус:



```bash

git status

```



---



## 4. Добавление файлов в коммит



Добавить все изменения:



```bash

git add .

```



Или конкретный файл:



```bash

git add backend/main.py

```



---



## 5. Создание коммита



Пиши понятные сообщения коммитов.



```bash

git commit -m "feat: добавил авторизацию"

```



Примеры:



```bash

feat: добавил websocket сервер

fix: исправил проверку токена

refactor: разделил backend на модули

docs: обновил README

```



---



## 6. Отправка изменений на GitHub

Пример:



```bash

git push origin dev

```



---



## 7. Структура веток



### Основные ветки



* `main` → стабильная версия

* `dev` → основная разработка



---



## 8. Правила проекта



### ДЕЛАТЬ



* Писать понятные коммиты

* Перед работой всегда делать pull

* Делать маленькие коммиты

* Работать через dev ветку



### НЕ ДЕЛАТЬ



* Не пушить напрямую в main

* Не хранить токены и секреты в репозитории

* Не работать всем в одной ветке

* Не делать огромные изменения в одном коммите



---



## 9. Полезные команды Git



### Посмотреть текущую ветку



```bash

git branch

```



---



### История коммитов



```bash

git log

```



---



### Проверить изменения



```bash

git status

```



---



### Получить обновления



```bash

git pull

```



---



### Отправить изменения



```bash

git push

```



---



### Переключиться на ветку



```bash

git checkout branch-name

```



---



### Создать и переключиться на ветку



```bash

git checkout -b new-branch

```



---



## 10. Соглашение по коммитам



| Тип      | Значение               |

| -------- | ---------------------- |

| feat     | новая фича             |

| fix      | исправление бага       |

| refactor | рефакторинг кода       |

| docs     | изменения документации |

| style    | форматирование         |

| test     | тесты                  |



Примеры:



```bash

git commit -m "feat: добавил шифрование сообщений"

git commit -m "fix: исправил reconnect websocket"

git commit -m "docs: обновил инструкцию установки"

```
